# Polices locales

Fichiers WOFF2 variables extraits de `@fontsource-variable/inter@5.3.0` et
`@fontsource-variable/bricolage-grotesque@5.3.0` (npm), sous-ensembles latin et
latin étendu, style normal. Les licences originales sont dans `public/licenses/`.

Déclarations, familles et rôles de texte : `src/assets/typography.css`.
Proposition actuelle : Inter pour les textes, Bricolage Grotesque pour les titres.
Les fichiers sont embarqués par Vite ; aucun CDN ni dépendance npm ajouté.

Pour Bricolage Grotesque, la version variable `wdth` remplace `wght` afin
de disposer de l'axe de largeur (75–100 %) pour le H2 condensé. Aucun second jeu
de la même police n'est conservé.
